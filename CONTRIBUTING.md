# Contributing to BhoomiSetu

Thanks for helping improve BhoomiSetu.

## Before you start

1. Open an issue describing the bug, feature, or proposed change.
2. Keep each pull request focused on one concern.
3. Never commit `.env` files, real credentials, or production data.

## Local setup

Install dependencies separately for `frontend` and `backend`. Copy
`backend/.env.example` to `backend/.env`, then supply a local MongoDB URI and a
strong JWT secret. See the README for the full run instructions.

## Pull requests

- Explain what changed and why.
- Test the affected frontend or API behavior before requesting review.
- Update documentation when configuration, API behavior, or user workflows change.
- Use clear, descriptive commit messages.
